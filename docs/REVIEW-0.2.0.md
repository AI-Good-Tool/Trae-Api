# 0.2.0 代码审查与验证

日期：2026-10-21。范围：地区隔离、API Key 编辑 / 随机生成、请求记录、应用图标、桌面打包。采用本地代码审查、自动化回归及界面操作验证；未执行 Git 提交或创建分支。

## 已修复的问题

1. **地区混用**：旧版本将两版账号和模型合并轮询。现在 `/cn/v1` 与 `/intl/v1` 在服务端隔离；默认 `/v1` 使用已保存地区。同名模型也只在对应地区的账号池内分配，指定账号进一步限制模型目录。
2. **部分设置写入**：旧代码可能先改账号，再因端口校验失败而留下半完成设置。现在先完整校验，启动失败恢复原设置；调整地区不会意外停止运行中的网关。
3. **请求诊断泄露与失真**：不再直接持久化上游任意错误文本，避免其中带入正文或令牌。记录固定错误说明及机器错误代码；SSE 未收到终止事件时记录为失败；流式请求区分实际 HTTP 状态与执行结果。
4. **密钥更新一致性**：格式校验、加密持久化失败回滚、随机源使用 Node crypto；旧密钥对下一次请求立即失效，不记录密钥正文。
5. **重启残留请求**：上次退出前的 pending 记录恢复为 cancelled，避免永久显示处理中。
6. **桌面与打包**：修复版本探测与单实例启动分支；图标同时用于侧栏、Dock 与 ICNS。打包采用文件白名单，不含账号库、用户配置、测试数据或开发依赖；签名失败会中止打包。镜像拷贝保留框架的相对符号链接，避免应用依赖构建目录。
