# v0.8.6 发布检查

- 默认启用官方云端反代及临时任务自动清理，启动时将旧的本地模式配置恢复开启；隐藏通道开关和本地模式提示，页面保存无需依赖已移除的控件。
- 仅清理网关本次创建的云端任务，成功、失败和取消均执行清理；后台重试带清理标记的失败记录，不清理既有历史会话。
- 本地通道实现保留在内部，不作为默认入口。包含模型能力缓存迁移、私有 IPC 运行实例隔离、断流检测、保活与并发创建数据库互斥。
- 打包只收录应用源码及资源，不包含本机账号、调试资料或截图。发布工作流验证每个安装包的 SHA-256 文件，三平台构建与启动检查全部通过后才创建 Release。
- 本机验证：67 项自动测试、格式检查、差异空白检查通过；Apple Silicon mac 安装包签名检查、DMG 校验及打包后启动冒烟通过，覆盖旧关闭配置迁移、隐藏入口及保存配置。
- 提交前人工审查未发现阻塞发布问题。Windows 和 Intel mac 的原生构建、安装/卸载与启动检查由 GitHub Actions 执行。
