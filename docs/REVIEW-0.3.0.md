# 0.3.0 审查与验证

本次审查覆盖模型归并、别名冲突、地区限制、账号选择、日志快照、签到重复领取与打包内容。未发现本次新增范围内的发布阻断问题。

- 模型按真实 model 字段归并，缺失时回退目录 ID；每个账号保留自己的配置 ID。显示名相似但真实名称不同的模型不自动合并。
- 所有地区共用模型规则，允许地区仅过滤已有模型账号，不能创造不存在的模型可用性。固定地区和指定账号不会越界。轮询按地区范围和真实模型分别计数。
- 别名编辑校验与真实名称、目录 ID、其他别名的冲突；刷新目录后出现歧义时拒绝请求。历史记录使用请求时名称快照。
- 顺序优先使用账号库当前顺序的第一个匹配账号；随机使用 crypto.randomInt；一次请求只调用一个账号，没有自动失败重放。
- 签到先查状态，确认未领取才调用 claim，随后重新查询确认；状态字段异常拒绝领取。国际版无该接口，不伪造签到。按北京时间判断当天状态，启动和每十分钟补签。执行历史只存元数据，错误内容脱敏。
- 保留旧版本地区与账号选择，升级后可选择“双区联合”；全新配置默认双区。
- 遵循 KISS / DRY：模型匹配集中在独立模块，签到执行和历史集中管理，无新增运行时依赖。

验证：18 项 node:test 全部通过，格式检查通过。测试覆盖共享模型跨区轮询、独有模型、显式地区、别名改名及日志快照、不同地区配置 ID、优先和指定账号、密钥更新、上游错误脱敏、签到幂等和并发。
界面使用隔离的虚构测试账号，验证编辑别名后目录立即更新；截图 docs/images/routing-0.3.0-test.png。不使用真实凭证调用收费聊天。

macOS arm64 包由构建脚本生成，codesign --verify --deep --strict 和 hdiutil verify 通过；SHA256 见安装包同目录校验文件。采用 ad-hoc 签名，未公证。

仍有已知限制：Trae 原生通用聊天上游链路适配尚未完成，本次路由 / 转换使用替身上游验证，不代表所有真实模型可调用。Responses、Messages、工具调用未接入；加密客户端数据库历史 Token 未解码。
