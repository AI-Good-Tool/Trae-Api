# 0.3.1 账号卡片与签到入口

账号池和总览复用同一账号卡片，直接显示国内积分余额、可用积分包数量、按到期时间排列的两个可用包及全部积分包弹窗。包余额来自官方 quota.credits_limit 减去 usage.credits_amount；无积分额度、隐藏包不展示，过期或用尽包不计入可用数量。国际美元额度保持独立显示。

国内卡片增加手动签到、今日状态及按账号自动签到开关，复用现有执行接口。工作台启动时补签，每十分钟检查，需保持应用运行。手动签到后刷新官方用量，自动领取成功后也刷新用量。国际版提示无官方签到入口。

检查内容：20 项测试通过；格式检查通过；隔离虚构账号 UI 验证卡片数值、包明细弹窗和自动签到开关保存。截图 docs/images/accounts-0.3.1-test.png。不向官方接口发送虚构凭证。

构建：0.3.1 macOS arm64，codesign deep strict 与 hdiutil verify 校验通过，ad-hoc 签名，未公证。无新增运行时依赖；积分包解析集中在 server/credits.mjs，UI 共用 packRows，遵循单一职责与复用原则。
